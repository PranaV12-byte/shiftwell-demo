# Shiftwell demo

A static HTML, CSS and JavaScript prototype for a scheduling product case study. It demonstrates automatic swap approvals, credential checks on the shift date, manager review and shared checks for initial assignments.

Three sample cases are included, along with unqualified and not-agreed colleagues. Staff and manager screens share the same in-memory request. Records are fictional and reset on refresh. No backend or external dependencies.

Open `index.html` locally, or use the GitHub Pages link when deployed.
